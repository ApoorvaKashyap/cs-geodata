.. py:function:: load_descriptor(descriptor_url: str, output_path: str) -> LayerConversionRequest

   Fetch and parse a TOML descriptor file into a LayerConversionRequest.

   Supports S3 URIs (via fsspec/s3fs) and plain HTTP/HTTPS URLs.

   :param descriptor_url: URL to the TOML file.
   :param output_path: Runtime output directory injected into the returned request.

   :returns: A fully-validated LayerConversionRequest.

   :raises ValueError: If the descriptor cannot be fetched or parsed.
