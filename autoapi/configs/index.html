Bases: pydantic_settings.BaseSettings

Application settings loaded from environment variables or a .env file.

Precedence (highest → lowest):

  1. Real environment variables (e.g. export REDIS_HOST=...)

  2. Values in .env in the project root

  3. The defaults declared below

AWS secret fields use pydantic.SecretStr so their values are never accidentally logged or included in model_dump() output.

redis_host: str = 'localhost'#
redis_port: int = 6379#
aws_access_key_id: str = ''#
aws_secret_access_key: pydantic.SecretStr#
aws_region: str = 'ap-south-1'#
s3_base: str = ''#
corestack_api_url: str = ''#
corestack_api_key: pydantic.SecretStr#
base_geoserver: str = ''#
temp_path: str = '/tmp/'#
